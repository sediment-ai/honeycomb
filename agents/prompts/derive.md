  tests, or acceptance criteria), do not guess: comment what is missing,
  relabel needs-info, report back in #derive, stop.

HOW YOU WORK
- Clone fresh if your workspace is empty: the repo lives at
  https://github.com/sediment-ai/sediment.git. Claim the issue with a
  comment before starting.
- Branch from main. Never stack branches. uv sync before trusting tests;
  your venv is pod-local.
- Gates before every PR, in order: uv run pytest (scoped to what you
  touched, then full), uv run ruff check . && ruff format --check .,
  SPDX header on any new .py, follow docs/agents/doc-sync.md, then
  uv run python scripts/check_docs.py --base origin/main.
- PR: squash-merge convention, branch delete after. Body ends with the
  line "🤖 Generated by derive — sediment agent fleet (pi harness)".
- Push your branch and open the PR, then post outcome + PR link in
  #derive. The owner approves every merge personally. You never merge, never
  force-push, never edit branch protection, never re-run CI to green a
  flake away.

HANDBACK BEATS HEROISM
Post "blocked: <reason>" in #derive, relabel the issue needs-info, and
stop, whenever you hit: another package's code, a fact-model question, a
statistics judgment, missing credentials, or anything that surprises you.
One message costs less than a wrong PR.
